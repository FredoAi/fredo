# Pipeline hygiene smoke tests

> **Adaptation note for this config-only slice (G-089):** the standard test-suite smoke boilerplate (`tauri_webview_dom_snapshot`, `tauri_read_logs`, app window render) does **NOT** apply — this spec has **no product runtime** and **no `telemetry_spans`** (a `live` smoke leg is unsatisfiable and would be a false gate). The smoke set below is adapted to the **system under test: the pipeline GitHub integration + repo config + the state machine's comment write path**, driven by the offline harness and the GitHub REST API / `gh` CLI. Each S-* case is a minimal, fast, pass/fail sanity check the tester runs first before the functional/regression/exploratory sets.

- [ ] S-1: Offline harness passes — `powershell -File .opencode/scripts/test-scripts.ps1` reports a passing run (total/passed/failed, zero failures, no skipped that short-circuit), confirming the state-machine action contracts and script integrity survive the hardening (NFR-HARNESS-1). This replaces the app-boot "no console errors" check.
- [ ] S-2: Product source tree untouched — a diff of the spec branch against `main` shows changes ONLY under `.opencode/scripts/pipeline-state.rs`, `.github/`, `docs/agentic-pipeline/`, `docs/SECURITY.md`, `CONTRIBUTING.md`; `git diff --name-only main...HEAD` contains no `apps/tauri/**`, `apps/ui/**`, or `apps/opencode-plugin/**` path (NFR-NOPRODUCT-1).
- [ ] S-3: All currently-open pipeline issues are locked — `gh issue list --state open --json number,labels` gives the pipeline set; for each, `gh api repos/FredoAi/fredo/issues/<n>` reports `locked: true`; the minimum set #2795/#2773/#2797 is present. (F-1 fast form.)
- [ ] S-4: State machine can still post a comment on a locked issue — a collaborating/machine `Status`-class comment on a benign or scratch locked pipeline issue succeeds (HTTP 201, appears on the timeline, no 403 lock error). (F-3 fast form; AC3 smoke.)
- [ ] S-5: Repo interaction limit reads `collaborators_only` — `gh api repos/FredoAi/fredo/interaction-limits` returns `limit: "collaborators_only"` (valid enum; not `contributors_only`/`existing_users`). (F-4a fast form.)
- [ ] S-6: No `telemetry_spans`/`cargo`/`pnpm` gate — verification for this slice must NOT require observing `telemetry_spans`, `cargo check` under `apps/tauri`, or `pnpm build`; a smoke PASS is obtainable from the offline harness + GitHub REST assertions + the product-tree-untouched check alone. If a tester's evidence depends on a native build to pass, that is an invalid (false) gate.
