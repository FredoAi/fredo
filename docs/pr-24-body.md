## Summary

Fixes the llama-cpp-sys-2 build failure on Windows by changing the CMake generator from `Visual Studio 17 2022` to `Ninja` in `.cargo/config.toml`.

## Root Cause

CMake 4.3 with the Visual Studio generator fails to produce `.vcxproj` target files when invoked from a Cargo build script, causing `cmake --build ... --target install` to fail with `MSB1009: Project file does not exist`.
