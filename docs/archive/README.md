# Archived Documentation

This directory contains documentation for components that have been superseded by the [Atlas desktop app](../tauri/ARCHITECTURE.md).

| Folder | What it was | Replaced by |
|--------|-------------|-------------|
| `browser-extension/` | Chrome extension that hosted `@atlas/ui` | `apps/tauri` |
| `tools-mcp/` | Node.js MCP/SSE backend API | Rust backend in `apps/tauri/src-tauri` |

These docs are preserved for historical reference and migration context.
